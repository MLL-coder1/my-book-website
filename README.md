# my-book-website

Site web de présentation pour le livre Project H.Lee. Le site affiche une page d'accueil inspirée de la couverture du livre, avec des chapitres et une structure simple pour publier au fur et à mesure.

## Aperçu

- Page d'accueil immersive avec une couverture de type science-fiction
- Navigation simple pour les chapitres, la présentation et le contact
- Design responsive pour mobile et desktop
- Structure prête à évoluer avec de nouveaux chapitres

## Démarrer

Ouvrez simplement `index.html` dans un navigateur ou servez le dossier localement via un serveur simple.

Exemple :

```bash
python3 -m http.server 8000
```

Puis ouvrez `http://localhost:8000`.

## Personnalisation

- Modifier le texte dans `index.html`
- Ajuster le style dans `style.css`
- Ajouter de nouveaux chapitres dans la section correspondante
